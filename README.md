## MyMangaApp

App created using SwiftUI and Async/Await. This app supports IPhone, IPad and Apple Vision Pro.

### MVVM and Clean

The app architecture uses View, ViewModel, ModelLogic, DTOs and Models. It uses the benefits of the framework to do the binding of the information between the different levels and doing a reactive app.

### Dependeces

It has no third-party dependencies. It uses all the native frameworks of the language.
